Technical Specifications

Built with enterprise requirements in mind

⚙️ Core Requirements

  • Odoo 18.0 Community or Enterprise
  • tesote.com API v2.0.0 account
  • Python requests library
  • PostgreSQL database

🔧 Architecture

  • RESTful API with Bearer token auth
  • Cursor-based incremental pagination
  • Singleton backend pattern
  • Extensible mapper/adapter design

🛡️ Security

  • HMAC-SHA256 webhook signatures
  • Secure credential storage
  • Odoo security group integration
  • Complete audit trail logging

📦 Deployment

  • Self-hosted Odoo installations
  • Odoo.sh cloud platform ready
  • Docker development environment
  • 112 unit tests included

API Endpoints

Full integration with tesote.com API v2

GET /api/v2/accounts Fetch all accounts
GET /api/v2/accounts/{id} Get account details
POST /api/v2/transactions/sync Sync with cursor
GET /api/v2/status Check API status
GET /api/v2/whoami Get client info

Webhook Events

Real-time notifications for instant data updates

sync.updates_available

Triggered when new data is available. Automatically initiates sync to fetch latest changes.

accounts.created/updated

Notifications when accounts are created or modified. Keep records in perfect sync.

transactions.created/updated

Instant alerts for new transactions or status changes in real-time.
